## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Vikash-malviya/Vikash-malviya.git
```

Navigate to the project:

```bash
cd Vikash-malviya
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
